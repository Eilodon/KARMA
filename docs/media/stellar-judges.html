What a labor market actually needs

Three real mechanisms, in the order a freelancer uses them — not a diagram, a ledger.

i
A private credit historyearn

A zero-knowledge proof that reputation clears a skill's threshold — without revealing the score, the job history, or the identity behind it. Checked on-chain by native BN254 host functions, not a software fallback.

ii
Payment the moment work is confirmedget paid

x402 settles USDC in the same request as the reputation proof — a signed Soroban authorization entry, verified and settled on-chain before the skill ever runs.

iii
A real path to local currencycash out

SEP-24 — the standard every Stellar wallet and anchor already speaks — opens a real interactive withdrawal against Stellar's own reference test anchor, toward money a freelancer can actually spend.

USDC 0.001 ≈ 25 VND · ≈ 400 IDR · ≈ 1.4 PHP — illustrative rate for scale, settlement itself stays in USDC.

Honest scope: the interactive URL opens an anchor-hosted KYC form — built for a human to click through by SEP-24's own design, a script cannot finish it server-side. What's proven real here is the full protocol handshake, independently confirmed twice — once via direct API, once by opening the anchor's own status page in a real browser (screenshot above). One thing found while testing: the anchor's SEP-10 JWT is short-lived (~10 min) — a production wallet must request a fresh challenge right before opening the interactive URL. Reproduce it yourself: KEYSTORE_PASSWORD=<password> pnpm exec tsx src/scripts/demo_stellar_anchor_cashout.ts.
